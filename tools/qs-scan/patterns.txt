# qs-scan pattern table.
#
# Format, one rule per line, tab separated:
#   id <TAB> severity <TAB> scope <TAB> extended-regular-expression
#
# severity: error | warn      (only `error` fails the gate)
# scope:    all | outside-tests
#           `outside-tests` skips anything under a `tests/` directory, because SYSTEM_PROMPT.md
#           permits explicitly named test doubles there (FakeUPower, MockPipeWire).
#
# This file is excluded from the scan by Scanner.cpp: it is the definition of the patterns, so it
# necessarily contains them.
#
# Matching is line by line, so an expression cannot span two lines: a failure handler whose braces
# start on the following line is not reported. A pattern table that silently under-reports is worse
# than none, which is why the limit is written down here and in SYSTEM_PROMPT.md.
#
# Deliberately NOT automated here, because a reasonable expression produces false positives on
# legitimate code or cannot be expressed at all. These stay human review items, listed in
# SYSTEM_PROMPT.md § Forbidden Patterns as "not machine-checked":
#   - filler names (foo/bar/baz): `bar` is a real domain word here (quantum-shell-bar, Bar.qml)
#   - canned return values (`return 55;`): no expression distinguishes a fabricated reading from a
#     real constant such as a protocol enum
#   - whether a code path can ever execute, and whether a default looks like a real reading
#   - whether a timer is a debounce/animation tick or a state poll
#
unfinished-work	error	all	\b(TODO|FIXME|XXX|HACK)\b
unfinished-work	error	all	not implemented|unimplemented|notimplemented|NotImplemented
stub-or-mock	error	outside-tests	\b(fake|mock|stub)[A-Za-z]*\b
filler-text	error	all	placeholder(?!Text)|lorem ipsum|sample data|\bdummy\b
prototype-marker	error	all	\btemporary\b|quick fix|will be replaced|for now
empty-catch	error	all	catch\s*\([^)]*\)\s*\{\s*\}
swallowed-exception	error	all	catch\s*\(\.\.\.\)\s*\{
# Two spellings, because the rule was blind in one of them until they were both written down: `QTimer`
# is the C++ one — the system status's cadence and the two reconnect backoffs are what it reports — and
# the clock's minute wake-up is a QML `Timer`, which the first spelling never saw. A gate that can only
# see the timer in one language cannot report the polling loop in the other, which is the whole point of
# the rule. Both are warnings rather than errors for the reason written in SYSTEM_PROMPT.md: whether a
# given timer is a state poll or a debounce is a judgement, and the rule's job is to make every one of
# them visible to a person reading the run rather than to decide it.
polling-timer	warn	all	QTimer
polling-timer	warn	all	(^|[^A-Za-z_])(Timer)[[:space:]]*\{
